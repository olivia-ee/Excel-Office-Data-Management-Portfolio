# Attendance Tracker

## Overview

This workbook records and summarizes employee attendance in a structured format. It is modeled after a simplified attendance register commonly used by human resources and administrative departments. The workbook demonstrates professional data organization, attendance tracking, and summary reporting using Microsoft Excel.

## Skills Demonstrated

- Excel Tables
- Cell Formatting
- Date & Time Formatting
- Sorting
- Filtering
- Freeze Panes
- COUNTA
- COUNTIF
- AutoFill
- Print Setup
