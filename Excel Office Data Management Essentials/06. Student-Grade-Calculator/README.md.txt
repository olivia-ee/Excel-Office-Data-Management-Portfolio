# Student Grade Calculator

## Overview

This workbook records and calculates student grades in a structured and professional format. It is modeled after a simplified class record commonly used by schools, colleges, and training institutions. The workbook demonstrates effective academic record management, grade computation, and class performance reporting using Microsoft Excel.

## Skills Demonstrated

- Excel Tables
- Cell Formatting
- Number Formatting
- AVERAGE
- IF
- MAX
- MIN
- COUNTIF
- Sorting
- Filtering
- Freeze Panes
- Print Setup
