# Employee Information System

## Overview

This workbook manages employee information, including department, position, employment status, and contact details. It is modeled after a simplified employee master file used by human resources departments.

## Skills Demonstrated

- Excel Tables
- Sorting
- Filtering
- COUNTA
- COUNTIF
- Professional Formatting
