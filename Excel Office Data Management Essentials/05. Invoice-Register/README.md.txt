# Invoice Register

## Overview

This workbook records and tracks customer invoices in a structured and professional format. It is modeled after a simplified invoice register commonly used by accounting departments, administrative offices, and small businesses. The workbook demonstrates effective invoice management, payment tracking, and financial record organization using Microsoft Excel.

## Skills Demonstrated

- Excel Tables
- Cell Formatting
- Currency Formatting
- SUM
- IF
- COUNTIF
- TODAY
- Conditional Formatting
- Sorting
- Filtering
- Freeze Panes
- Print Setup
