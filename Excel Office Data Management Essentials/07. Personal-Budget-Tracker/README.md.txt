# Personal Budget Tracker

## Overview

This workbook records and summarizes personal income and expenses in a structured and professional format. It is modeled after a simplified budget tracker commonly used to monitor daily spending, monthly expenses, savings, and available funds. The workbook demonstrates effective financial data organization, expense tracking, and budget reporting using Microsoft Excel.

## Skills Demonstrated

- Excel Tables
- Cell Formatting
- Currency Formatting
- SUM
- SUMIF
- AVERAGEIF
- MAXIFS
- MINIFS
- Sorting
- Filtering
- Freeze Panes
- Print Setup
