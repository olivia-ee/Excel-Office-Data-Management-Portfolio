# Sales Record Tracker

## Overview

This workbook records and summarizes daily sales transactions in a structured and professional format. It is modeled after a simplified sales register commonly used by retail stores, small businesses, and administrative offices. The workbook demonstrates effective data organization, transaction recording, and basic sales reporting using Microsoft Excel.

## Skills Demonstrated

- Excel Tables
- Cell Formatting
- Currency Formatting
- SUM
- AVERAGE
- MAX
- MIN
- Sorting
- Filtering
- Freeze Panes
- AutoFill
- Print Setup
