# Task & To-Do Manager

## Overview

This workbook records and monitors tasks in a structured and professional format. It is modeled after a simplified task register commonly used by employees, administrative offices, and small teams. The workbook demonstrates effective task organization, deadline monitoring, priority tracking, and task status reporting using Microsoft Excel.

## Skills Demonstrated

- Excel Tables
- Cell Formatting
- Date Formatting
- IF
- COUNTIF
- COUNTA
- TODAY
- Conditional Formatting
- Sorting
- Filtering
- Freeze Panes
- Print Setup
